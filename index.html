Change your profile theme from this page

Paste a key that can only start the city workflow on your profile repo. It is saved in this browser only and sent only to GitHub.

  1. Open GitHub → new fine-grained token.
  2. Name it gitworld. Under Repository access choose Only select repositories and pick your profile repo.
  3. Under Permissions → Repository permissions, set Actions to Read and write. Leave everything else as is.
  4. Click Generate token, copy it, and paste it below.
